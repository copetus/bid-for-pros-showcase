# Bid for Pros — public app showcase

[View the showcase](https://copetus.github.io/bid-for-pros-showcase/)

Dated, unretouched screenshots from the evolving iOS prototype. Sample profiles, prices, and recommendations are fictional; this is not a live service.

This repository contains the published static website and reviewed screenshots only. The app and project planning are maintained separately. Updates to main are automatically published by GitHub Pages.

Site files are generated from the project’s showcase sources; changes should be made there and republished. Screenshot collections remain available by date as the app evolves.
